# Product

## Platform

web

## Stack
Existing codebase: plain static HTML/CSS/JS in `site/`, published with GitHub Pages (GitHub Actions). Three.js r160 self-hosted in `site/assets/vendor/` and loaded via import map (scene loaded lazily; UI works without it). No build step. Bilingual ES/EN through `site/assets/i18n.js`.

## Users
Independent designers and small apparel brands who prepare their own artwork for DTF/DTG printing in Adobe Photoshop and do not want per-seat licenses or subscriptions. They arrive from a search or a recommendation looking for a free way to make halftones with a knockout of the garment color. Print shops are a secondary audience and are not the priority of the page.

## Product Purpose
Open-DTF is a free, open-source (MIT) Photoshop plugin (UXP panel) that prepares artwork for DTF/DTG: resizes to 300 ppi, removes the garment color (knockout), builds the halftone with live adjustments, and outputs one transparent layer. The website exists to make the plugin findable, explain how it works in five steps, and get a designer to download it. Success is a download and a first run in Photoshop.

## Positioning
Open-DTF is the free alternative to paid halftone plugins: MIT license, the halftone is built with Photoshop's own native features (adjustment layers, pattern fills, filters) and never by processing pixels in JavaScript, it works on a duplicate (non-destructive), and it runs offline with no network permissions. Paid plugins are described generically; no competitor is named.

## Operating Context
Photoshop 2022 (23.3) or later on Windows or macOS (tested on Windows only so far). Output is a PNG-ready transparent layer handed to the user's own RIP; Open-DTF does not replace the RIP, ink management or the white underbase. Distribution: `.ccx` file from GitHub Releases, installed by double-click through Creative Cloud. Contributions and bug reports through GitHub issues.

## Brand Commitments
Name "Open-DTF" and its mark (three growing halftone dots with "Open" set in italic serif and "-DTF" in sans). Binding by the user. The accent blue of the plugin panel and the existing 3D story are not binding.

## Evidence on Hand
No real screenshots of the plugin, no before/after, no testimonials, no user counts, no benchmarks. Future work must not fabricate any of these. Illustrations and the 3D scene are generated by code (a procedural poster and an optimized CC BY shirt model).

## Product Principles
1. Free and open is the offer: say it plainly and never hide the license.
2. Show the mechanism (halftone dots, knockout) instead of describing it.
3. Claims stay verifiable: no invented numbers, customers or competitor names.
4. The download is always one clear action away.
5. Honest about limits: Photoshop only, tested on Windows, does not replace the RIP.

## Accessibility & Inclusion
Keep AA contrast, visible focus, keyboard-operable demo controls and FAQ, and a reduced-motion path. Spanish and English are equally supported.
